# Ruptured MCA Aneurysm in a Neonate

- **Case report and operative video:** Zeitouni D, Drossopoulos P, Pugh BA, et al. *Operative Neurosurgery*. 2026;31(3):613–614. [DOI](https://doi.org/10.1227/ons.0000000000001913), [PMID 41537666](https://pubmed.ncbi.nlm.nih.gov/41537666/). © Congress of Neurological Surgeons 2026. The public guide contains original instructional prose and drawings. The local file control plays a reader-selected copy and extracts stills in the browser. It does not send that media to the site.
- **Anatomy:** [Z-Anatomy](https://github.com/Z-Anatomy/Models-of-human-anatomy/tree/bb293be456f6d2245191f37752d14ec76894740d), [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Upstream BodyParts3D by DBCLS, [CC BY-SA 2.1 Japan](https://creativecommons.org/licenses/by-sa/2.1/jp/). The supplied archive matches the pinned revision. The native bones, cortex, temporalis and MCA are in the reference's shared coordinates. The case uses derived osteotomies and cut edges, fitted scalp and membranes, and illustrative pathology and instruments. The underlying documented atlas is adult anatomy. Mesh names, native object matches and transformations are in the model provenance.
- **Anatomical figure:** Giotta Lucifero A, Baldoncini M, Bruno N, et al. *Acta Biomed*. 2021;92(Suppl 4):e2021412, [Figure 5, p. 9](https://pmc.ncbi.nlm.nih.gov/articles/PMC9179062/). [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Extracted and resized, with CMYK converted to RGB. Adult cadaveric anatomy provides related context.
- **Case viewer:** adapted from the [operative website skill’s retained Pterional viewer](https://github.com/nyuolab/operative-website-skill), including the camera, tissue shaders, curl/peel, picking, reader and mobile controls. This case reuses the retained registered Z-Anatomy cranial meshes and fitted soft-tissue layers.

## Preview and edit

Open the standalone HTML in a browser for offline use. To preview the extracted site folder, open the folder in VS Code, start `python3 -m http.server 8000` there, and visit `http://localhost:8000/`. The guide page is `index.html` and the viewer code is `assets/app.js`. The compressed assets contain the atlas geometry and case data.

The hosted version can load the recording with **About → Load MP4**. The file remains in the browser. The timestamps correspond to the 11-minute 6-second recording. Steps outside the microscope footage may include a contextual source frame.
